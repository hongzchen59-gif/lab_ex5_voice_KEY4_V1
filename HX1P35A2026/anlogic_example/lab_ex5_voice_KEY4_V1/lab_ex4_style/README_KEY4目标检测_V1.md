# KEY4 彩色几何目标检测 V1

本工程从 V2.1 独立建立，新增 KEY4 目标检测。摄像头 SC500CS、基础 Gamma 0.60、30fps 目标配置、AE/AWB 及原视频链路沿用；V2.1 原工程与 bit 保留。

## 按键与使用

| 按键 | 功能 |
| --- | --- |
| KEY1 | ORIGINAL，基础 Gamma 后的正常图像 |
| KEY2 | EDGE，黑底白色边缘 |
| KEY3 | CARTOON，保留 V2.1 自然插画 |
| KEY4 | DETECT，正常图像 + 彩色目标框 + 识别结果 |

按 KEY4 后，右上角显示检测状态和数量，下面最多四行显示颜色、形状及中心坐标。目标框为两像素宽，红/绿/蓝框对应目标颜色。X/Y 使用外接框中心，单位是 1280×720 显示画面的像素，左上角为 (0,0)，数字为十进制。

可识别 RED / GREEN / BLUE 三种颜色，以及 CIRCLE / TRIANGLE / RECT；正方形归为 RECT。颜色与形状分别判断，例如蓝色圆形仍应显示 BLUE CIRCLE。UNKNOWN 表示发现了合格彩色区域，但形状不满足确认规则；该区域仍计入目标数量。

推荐先使用浅色背景下的实心彩色卡片，目标近正面、基本直立、相互分离，宽高至少约 64 个原图像素。可先摆红圆、绿三角、蓝矩形，再交换颜色检查。两个同色目标需要保持间隙；接触或严重遮挡后可能成为同一连通区域。

| 显示 | 含义 |
| --- | --- |
| RUN / COUNT:0～4 | 当前分析有效，数量为合格彩色连通区域数 |
| RUN / COUNT:4+ | 至少五个合格区域，仅绘制面积最大的四个 |
| WAIT / COUNT:-- | 启动等待或未取得完整采集帧，不显示有效框 |
| OVERFLOW / COUNT:-- | 当前帧游程/临时标签超容量或后台任务超时，清除有效框 |

检测结果来自较早的显示帧，适合静止和缓慢移动目标。按当前调度，采集帧 N 通常在 N+2 显示结果，两个显示帧起点相距约 33ms；这不包含完整摄像头、DDR 和显示器延迟。检测一直运行，KEY1～3 隐藏其框与文字。首版直接发布每张有效分析结果，未启用可选的跨帧类别确认，避免额外增加响应延迟。

## 实现与参数

- 从顶层 `S_aligned_pixel` 分支取 ISP/AWB 后、Gamma/风格/OSD 前的 RGB888，不新增 DDR 访问端口或检测结果 CDC。
- 像素颜色条件：最大通道不低于 48，最大最小通道差不低于 24，主色通道比另外两通道均至少高 16。这是初始门限，尚需用户实际光线下上板验证。
- 4×4 块统计三色票数；唯一最高票且至少 8 票才输出该色，否则为背景。320×180 分类掩膜双银行，净载荷 230400bit。
- RLE 同色八连通，最多每行 64 个游程、每帧累计分配 128 个临时标签。上一行区间向左右各扩一格后与当前行比较；按秩合并使根查询深度有界。
- 区域面积至少 96 个检测单元，框宽高各至少 16 个单元；过滤触图像边界及宽高比例超过 4:1 的区域。
- 形状使用填充率、宽高比、相对质心及五个高度处的区域行宽。保存最终标签映射后确定性回放掩膜，剖面只累计对应连通域，不混入同框内其他同色区域。
- 背景计算截止为 1000000 像素时钟拍；下次银行交接可强制中止旧任务，采集及 HDMI 不等待后台。
- 结果在 mixer 自身输入 SOF 整表锁存，沿用公共风格延迟和原 Logo 三拍对齐。`frame_id` 是内部掩膜任务序号，不是传感器回读的帧 ID。
- 旧 KEY4 专属 gamma85 和高斯锐化运算已移除；KEY3 的保边平滑、量化、19/16 饱和度和软轮廓保留。

## 仿真

使用用户指定的 ModelSim：

```powershell
Set-Location -LiteralPath 'D:\Anlogic\HX1P35A2026\anlogic_example\lab_ex4_style_SC500_720P_30FPS_KEY4_DETECT_V1\lab_ex4_style'
& '.\sim\run_modelsim.ps1' -ModelSimDir 'D:\FPGA\Modelsim\modelsim_ase\win32aloem'
```

脚本执行七组基础回归和五组新增检测测试，共十二组。可以通过 `-Benches` 指定单组测试；每组必须打印 PASS，脚本不只依赖 ModelSim 的退出码。`detect_reference.py` 使用独立 BFS 生成连通区域参考，并校验颜色/形状组合。

新增测试：掩膜投票与异常帧；连通域/几何/BCD 与容量边界；后台截止；OSD 文字与框线；完整 720p 检测集成。详细结果见同目录验证记录。

## 构建与交付

```powershell
& 'D:\Anlogic\TD_6.2.1\bin\td_commands_prompt.exe' 'D:/Anlogic/HX1P35A2026/anlogic_example/lab_ex4_style_SC500_720P_30FPS_KEY4_DETECT_V1/lab_ex4_style/scripts/build_td.tcl'
```

TD 工程为 `td_project/camera_to_dsi_display.al`；bit 输出在本工程 `td_project/cli_build/camera_to_dsi_display.bit`。构建脚本从源码开始，最终读取布线后建立/保持余量，非负才打印 `STYLE_TD_BUILD_FINISHED`。具体是否已成功及最终资源，以验证记录与构建日志为准。

算法仿真不能替代实物光照、摄像头颜色、运动及识别观感的上板验收。首先按 KEY4 使用同一机位的彩色卡片验证，再反馈需要调整的颜色门限或类别表现。
