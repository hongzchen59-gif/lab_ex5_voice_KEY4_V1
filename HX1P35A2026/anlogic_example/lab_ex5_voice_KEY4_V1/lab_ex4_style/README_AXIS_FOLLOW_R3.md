# AXIS_FOLLOW_R3：抑制上下越过中心后的反复摆动

**当前源码已进入AXIS_FOLLOW_R4 / VOI6，见README_AXIS_FOLLOW_R4.md。**用户反馈R3仍有快速下转/上下晃动，R3构建和仿真通过不能代表实机稳定性通过。下文为R3历史记录。

用户确认R2启动与自检通过，启动后p读取status=0、cfg=0、servo_us=1500，随后发现上下晃动发生在跟踪静止目标时：先接近中心，再越过中心来回摆。本版针对这个反馈调整上下控制，不把此前的45度下转直接判定为舵机自身上电复位。

## 本次改动

R2每20ms重复使用最近一次坐标，视觉反馈尚未更新时，舵机仍可能连续累加原方向的位移。本版上下轴每个新的有效视觉结果最多修正一次，修正量仍按偏差分为4/12/24us；重复传送同一结果帧不再继续追加上下位移。更新仍在20ms控制节拍消费，PWM继续50Hz帧边界更新。

中心保持采用两个阈值：

- 停止状态下，垂直偏差必须超过64像素，且连续两帧方向一致，才开始调整。偏差刚超过阈值的一帧不动。
- 已在调整时，偏差减小到40像素以内便保持当前位置；同侧偏差在40～64像素之间保留原运动方向，避免在同一阈值边界反复启动/停止。
- 反向也需要连续两帧确认。第一帧反向偏差先停止追加，第二帧仍在反向启动区才开始反向。单帧跳点不会立即反打舵机。
- 目标无效、冻结帧超时、切换口令和退出跟踪会清掉方向确认及待修正状态，恢复有效结果后重新确认。

每个结果的偏差绝对值>160像素用24us、81～160像素用12us，其余有效调整用4us。这是位置指令增量，不是已测得的角速度。新结果若为30次/秒，最大持续指令变化约720us/s；实际视觉结果频率、舵机负载与响应仍影响物理跟随速度。该控制未进行机械模型辨识，尚不能声称闭环已经稳定或保证不再晃动。

视觉选择模块同步修正：新帧候选扫描期间保留上一份已提交的坐标/有效位/结果帧号；扫描COMMIT时一次发布新结果，避免每帧扫描前产生短暂的假丢失。新口令、检测状态失败仍立即清掉目标；COMMIT发现无匹配候选时明确提交无效结果。没有延长500ms冻结帧超时。

水平控制沿用R2的原逻辑，水平±1024脉冲、舵机1000～2000us工作限位、j/l±32脉冲、i/k±50us均保留。方向仍为l俯视顺时针、i上/k下。舵机安装角度、1500us机械中心及180度全行程尚未标定。

## 下载与观察

本版FPGA ID为VOI5（0x564f4935），固件启动标记VOICE_KEY4_V5 AXIS_FOLLOW_R3。需要同时更新bit和ELF。

1. 当前程序发d关闭输出，结束FD/OpenOCD调试。
2. TD直接下载 `td_project/cli_build/camera_to_dsi_display.bit`，随后关闭TD下载连接。用FD加载 `D:/Anlogic/FDwork/voice_key4_app/build/voice_key4.elf` 并Resume，确认R3标记和自检通过；COM11先打开。
3. a选红色圆形或b选蓝色方形，先保持目标静止；f开启跟踪。目标接近中心后应进入保持区，观察是否还持续反向摆动，再移动目标观察跟随。
4. e退出自动到手动；s保持；d关闭输出。d仍是CPU串口命令，录音/分类忙时不当作独立硬件急停。x/y翻转反馈并退出自动模式，只有实际方向错误时才用；本次用户反馈为越过中心后的摆动，不默认翻转方向。

R2配套bit/ELF及修改前核心源码保存在 `D:/Anlogic/方案/axis_follow_r2_before_stability_20261023`。回退用其中axis_follow_r2.bit及axis_follow_r2.elf配套下载。
