## 本轮实现范围

1. 片内 RISC-V 硬核接入：Core 300 MHz、Timer 50 MHz、AHB 分频 2、PAD JTAG、UART0 115200。
2. INMP441 I²S 主时钟与单声道接收，24 位补码、32 位时隙、标准一位延迟；采集时钟持续运行，启动等待 300 ms。
3. 4 KiB PCM 乒乓缓冲；未释放银行不覆盖，溢出停止录音并置错误。
4. AHB 到 50 MHz 本地寄存器/RAM的应答式跨域桥；只允许对齐的 32 位访问，非法访问返回两周期 ERROR。
5. 48 KiB ERAM 工作区，用于四个模板及一个待识别特征序列。RAM不整块复位，固件使用前初始化相应槽。
6. CPU 软件 MFCC + 受限 DTW、端点、质量检查与拒识；默认未标定时拒识。
7. 命令跨域握手和 KEY4 目标选择结果。切换时清除旧结果，丢弃前两次新分析结果，停止/回中请求清除当前选择。

KEY1~4原显示模式保留。KEY1 + KEY4 同时按住超过约20 ms可触发识别；组合键不是训练入口，未录入模板或未配置阈值时提示 NOT_READY。依次按下可能短暂切换显示模式，不会停止检测。

## 采样与算法

本版本明确采用 15,625 Hz：50 MHz分频50得到1 MHz SCK，每帧64个SCK。不是将近似时钟标为16 kHz。

PCM为单声道有符号16位，24位样本取高16位。每银行1024样本、2048字节，约65.536 ms。CPU必须及时读完并释放，不能通过暂停麦克风时钟回压。

MFCC：400样本窗、160样本帧移，对应25.6 ms/10.24 ms；512点FFT、26个Mel通道（80~7000 Hz）、DCT C1~C13、Q6量化，再进行整句倒谱均值归一化。最长3秒，最多300帧。每条模板7800字节，四条模板加一次查询共39000字节，放在48 KiB Fabric RAM内。

只保存每类一个模板，用于先验证完整口令链路。没有训练多人模型，没有测得准确率或延迟。重复录入会替换该类模板；复位/断电后模板无效。比赛用非易失模板和冷启动还未实现。

## 串口联调流程

这是开发阶段使用电脑的调试入口；不能把它当作已完成的脱机比赛流程。

1. 使用匹配本版本的bit和ELF调试。固件是TCM调试装载，不会自动烧写Flash；不能只下载bit就期待语音程序运行。
2. 串口115200 8N1，等待`MFCC_SELFTEST=PASS`和`FABRIC_ID_RAM_PASS`。这些文字只有实际板上执行后才是硬件证据；主机编译通过不等于已经打印。
3. 发送`1`并说“追踪红色圆形”；`2`为“追踪蓝色方形”；`3`为“停止追踪”；`4`为“云台回中”。每次录完检查帧数、峰值、截断或溢出。录音期间不要大量发送串口数据。
4. 阈值默认0、拒绝执行识别。用实际正/负录音标定距离阈值和类别间隔后，输入`T 距离阈值 类别间隔`并回车。这两个值没有通用保证，随意放宽会增加误触。
5. 发送`r`或按组合键录入待识别语音。固件打印每类DTW距离、拒识原因、分类周期数及命令确认。
6. `p`查看硬件状态与选中坐标；`s`、`h`是明确标记的串口命令接口测试，不是语音识别结果。

当前HOME只提交回中状态请求，不产生舵机/步进动作。X42S与轮趣S20F的轴适配、舵机角度版本、零点和限位、驱动器内置处理器的比赛许可仍需落实。

成功录音后`MAX_BLOCK_CYCLES`给出读出/处理一个PCM银行的最大周期数；按配置300 MHz预算应小于19660800周期并留余量。它不包含等待银行填满的时间，也不替代溢出检查。`CLASSIFY_CYCLES`包含串口打印各类距离的开销，不能当成纯DTW计算周期或实际端到端延迟。

## 寄存器接口

CPU基址0x80000000。所有寄存器与RAM均只允许对齐32位读写。

| 偏移 | 含义 |
|---|---|
| 0x00 | ID=0x564f4931 |
| 0x04 | 采样率15625 |
| 0x08 | 写1开始录音；写0停止；写控制会清理本轮计数与银行标志 |
| 0x0c | bit0麦克风就绪，1采集中，2/3银行就绪，4溢出，5命令忙，6录音组合键 |
| 0x10 / 0x14 | 本轮样本计数 / 完成块计数 |
| 0x18 | 写bit0/1释放对应已读银行 |
| 0x20 | 命令：[7:0]操作、[15:8]颜色、[23:16]形状 |
| 0x24 | 命令握手忙；忙时不能覆盖未消费命令 |
| 0x28 | 选中坐标：低16位X、高16位Y |
| 0x2c | [31:16]代次、bit8有效、[7:0]操作；先看有效位再解释坐标 |
| 0x1000~0x1fff | 两银行PCM；每字低16位为较早样本，高16位为较晚样本；只读 |
| 0x10000~0x1bfff | 48 KiB特征/模板工作区 |

操作1选择、2停止、3回中请求。颜色1红、2绿、3蓝。形状1圆、2三角、3矩形、4方形。方形在矩形分类基础上增加宽高比7/8~9/8限制，只针对近正面、基本直立图形；不声称任意旋转方形识别。

重复SELECT按重新获取处理：仍清空旧坐标并等待两次新分析结果。重复STOP/HOME保持停止/回中请求状态。命令邮箱忙时不覆盖，CPU等待ACK；录音或分类执行期间不接受第二次录音触发。

目标坐标从二进制外接框求中心，不解析显示BCD。多目标先确定一个候选，已有有效选择时按邻近中心关联；不是跨遮挡的持久ID追踪。原检测任务号不是传感器源帧号，重复视频帧和完整端到端延迟仍需上板分析。

## 构建与验证

- `sim/run_voice.ps1`：新增音频、AHB、缓冲、命令测试。
- `sim/run_modelsim.ps1`：原十二组视频/检测回归。
- `scripts/build_td.tcl`：完整源码构建；必须检查最终建立/保持和资源，不能只凭bit文件存在判断成功。
- FD Application的`build.ps1`：离线生成常量/独立DFT自检向量并编译ELF。

FD初次ASCT生成时，SDK的LIB_LOG仍引用旧PS_DRIVER_UART，已在本工作区的system.mss中修正依赖。安装包没有找到ddr_config_gen.exe；本平台不使用CPU DDR初始化，使用已生成的BSP文件并通过实际编译验证，未修改FD安装目录。后续重新生成BSP需保留本项目的配置，不能盲目换回安装目录默认HPF。

固件使用官方TCM链接布局；关闭浮点printf（算法仍使用FPU），为栈分配2 KiB，关闭链接松弛以避免启动栈地址重定位错误。未增加神经网络硬件加速器。

AHB与50 MHz之间仅为应答式跨域桥。为避免TD打包改变寄存器名而丢失约束，双向跨域按时钟对象设置有限的datapath-only最大延迟（请求20 ns、响应10 ns），仅取消这两方向不适用的相位保持关系；不是将建立检查设为false-path。像素到50 MHz的遥测/ACK同样设20 ns有限上限。同步链第二级、域内逻辑均继续按各自时钟检查。今后若增加这些方向的其他直接通路，必须重新审查此约束假设。最终例外报告已核对实际覆盖数和Slack，不能仅看SDC文本。

本版本必须实测：CPU启动和AHB、麦克风电气/声音、MFCC自检、块处理时间、DTW耗时、拒识及实拍目标选择。本机仿真不能替代这些结果。

## 上板验收顺序

| 阶段 | 工作与产物 | 验收方式 |
|---|---|---|
| 1 处理器/数据通路 | 配套bit与TCM ELF、启动日志 | 板上看到MFCC_SELFTEST及FABRIC_ID_RAM_PASS；确认UART波特率、配置时钟，重复读写不死锁。RTL仿真仅覆盖AHB桥协议，不覆盖硬核启动。 |
| 2 麦克风 | 核对3.3 V、排针、L/R；检查SCK/WS/SD | 示波器/逻辑分析仪实测1 MHz、15.625 kHz、32位时隙和一位延迟；录制已知声音检查幅度/符号/失真。仿真已检查序列和符号，不能证明实际声音正确。 |
| 3 录音与缓冲 | KEY1+KEY4录音及超时/溢出日志 | 静音、短按、长按、连续触发，检查样本数和银行释放；人为延迟消费确认拒识且下一次可恢复。测量每银行总处理时间，小于65.536 ms并留余量。 |
| 4 识别 | 先单口令，再四个完整中文口令；实际模板/阈值记录 | 先确认MFCC自检。分开录入与测试语音，按类统计正确、误识别、漏识别、拒识和周期数；未知语音与静音必须加入阈值标定。当前每类仅一个易失模板，不能声称多人通用。 |
| 5 目标命令 | 选择/停止/回中请求、目标代次与坐标 | 先串口命令验证，再换语音。切换后旧坐标清零；两次分析结果被丢弃；STOP/HOME无有效目标。实际电机适配完成前HOME不会运动。 |
| 6 场景测试 | 距离、说话人、背景噪声和电机噪声测试表 | 电机控制接入后测静止/运行两组；记录触发到确认、录音终点到结果的延迟，以及每类混淆情况。资源和延迟先设目标，再据实测决定是否扩模板或换模型。 |

录音与计算不暂停摄像头和原检测；已选目标继续更新。仅在新语音被接受时切换目标并清理旧选择；无效录音不改变当前目标。该阶段没有云台闭环输出，因此实际轴在录音期间如何保持/限速，待电机控制接入时验证。

电脑当前用于生成常量、编译、调试和串口录入触发；采样、MFCC、DTW均设计为片内运行。比赛前仍须完成模板非易失存储、阈值固定和断电冷启动验收，之后才能移除开发用电脑。当前版本不满足完整比赛脱机交付条件。
