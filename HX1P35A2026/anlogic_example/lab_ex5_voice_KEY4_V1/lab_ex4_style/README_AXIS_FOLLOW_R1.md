## 完成范围与证据边界

语音特征提取、DTW及目标状态选择继续由片内RISC-V与FPGA完成；新轴反馈、步进脉冲和PWM均在50MHz FPGA域运行，不依赖CPU主循环轮询。因此录音/识别期间仍可跟随原有有效目标。语音被接受后，命令邮箱同时取消旧运动和旧目标，再等待新的匹配结果。尚未实测闭环跟踪效果、稳定性、全行程和多人语音准确率；不能用点动成功代替闭环硬件验收。

已经验证正常的点动版bit、AXIS_JOG_R3 ELF及相关源码备份在 `D:/Anlogic/方案/axis_jog_r3_before_follow_20261022`。原KEY4检测基线不修改。

## 控制参数

- 1280x720画面的参考中心为(640,360)，水平死区±32像素、垂直死区±24像素；进入死区后停止该轴的追加调整，保留当前角度。
- 每20ms计算一次。水平偏差超过160像素时目标为当前位置外2个脉冲，否则为1个，方向由偏差符号决定；不累积无限的待执行位置队列。现有STEP发生器仍限约100脉冲/秒，10us高电平、20us方向建立时间。
- 垂直偏差超过80像素时每次改变4us，否则为2us；目标在画面上方时默认增加脉宽（已知对应机构向上），下方则减少。PWM仍为50Hz，脉宽在帧边界更新。
- 保留水平相对软件零点±128脉冲、舵机1300..1700us的初期限制。这是受限范围的首次闭环，不能保证全画面范围都能居中。实际水平角度取决于细分和传动比；1500us不等于已标定机械中心。
- 当前算法为带死区的分档增量控制，不是已调参PID。抖动、响应速度、镜像方向等需结合实际云台调试；本版不报告未经实测的精度和延迟。

## 帧一致性和丢失处理

视觉选择模块增加result_frame_id，仅在目标坐标COMMIT时更新。它与info、XY通过同一个80位持有负载握手机制跨域，避免把新帧号与旧坐标配对。控制器核对命令代次、SELECT操作、目标有效位及坐标范围。

同一结果帧被CDC重复送达不会刷新超时；必须有新的已提交结果帧。500ms没有新结果则失去fresh资格，最迟下一次20ms控制更新撤销待执行位移并保持舵机当前已发出的脉宽。明确无目标/状态无效的包会立即触发撤销。驱动器保持使能以保持姿态，不自动大范围搜索目标。

这里的帧号是视觉分析结果号，不能据此证明摄像头传感器本身一定没有重复旧视频帧。摄像头冻结/数据源健康仍属于原视频链路待验证项。

STOP清除待执行位移并保持；HOME在启用时回到软件水平零点与1500us，而不是物理限位回零。新SELECT立即清掉旧目标，等待选择模块丢弃两次分析结果后再获得新目标。d关闭脉冲/PWM并撤销EN，CPU录音/分类期间串口指令需等待主循环，不将d当作独立硬件急停。

## 配套版本和首次运行

FPGA基址ID改为VOI3（0x564f4933），FD启动标记为VOICE_KEY4_V3 AXIS_FOLLOW_R1；不能与点动VOI2混用。所有新增模式默认关闭。TCM加载后仍需从_start运行，模板和阈值易失，比赛所需的模板持久化及冷启动尚未完成。

1. 在当前正常运行的旧程序发送d，再结束FD/OpenOCD调试。由TD下载本版通过最终时序检查的bit，关闭TD下载连接，再用FD加载本版ELF。COM11先打开，避免共享USB接口重枚举造成旧调试句柄失效。不要同时启动多个Debug会话。
2. Resume后确认AXIS_FOLLOW_R1、MFCC_SELFTEST=PASS、FABRIC_ID_RAM_PASS。发p读取轴状态与FOLLOW行。
3. 先不重录语音：发a选择红色圆形，或b选择蓝色方形。将目标置于视野内靠近中心，发p确认TRACK目标有效、XY在合理位置。
4. 发f开启自动跟踪；目标缓慢移动时观察两轴是否让目标靠近画面中心。发e返回手动模式，d关闭输出。若反向，先发e，再发x翻转水平反馈符号或y翻转垂直反馈符号，之后f重新开启；翻转命令本身也会退回手动并撤销待执行运动，不需要重新编译。
5. 方向确认后再逐条录入1..4，并设置临时联调T参数或经验证的阈值。语音r/KEY1+KEY4识别和串口a/b/s/h使用同一个命令接口，不是两套目标状态。临时T 500 20只沿用此前口令联调经验，不代表非目标语音拒识已通过。

## 串口指令

| 指令 | 行为 |
|---|---|
| e | 启用手动模式，停止反馈追加运动 |
| f | 启用自动反馈；尚无有效SELECT目标时保持 |
| d | 关闭输出 |
| a / b | 选择红色圆形 / 蓝色方形，不需要语音模板 |
| s / h | STOP保持 / HOME软件回中 |
| j / l | 手动水平-32/+32脉冲 |
| i / k | 手动垂直+50/-50us |
| z | 手动停稳时设置软件水平零点，不绕过机械限位 |
| x / y | 翻转水平/垂直反馈方向并返回手动；不改变j/l/i/k的点动方向 |
| p | 原状态、AXIS状态、FOLLOW配置/新鲜度/帧龄/帧号 |

自动模式下拒绝手动点动和清零请求，先e切回手动。语音录入和T配置规则不变，T仍须带回车或换行。

## 寄存器增量

基址仍为0x80000000，0x30控制bit0启用、bit1跟踪模式、bit2水平反馈反向、bit3垂直反馈反向；0x40状态新增bit5跟踪模式、bit6目标fresh，原低5位保持。0x50为结果帧龄ms（饱和500），0x54为最后提交结果帧号。其余点动寄存器和音频RAM布局不变。新固件先检查VOI3再访问新增寄存器。
